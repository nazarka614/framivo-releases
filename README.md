# Framivo

Скриншоты и запись экрана — просто и красиво. Всё остаётся на твоём компьютере.

**Скачать:** https://nazarka614.github.io/framivo-releases/ или в разделе [Releases](../../releases/latest).

| Система | Файл | Что работает |
| --- | --- | --- |
| Windows 10/11 | `Framivo_x.y.z_x64-setup.exe` | снимки, редактор, запись видео |
| macOS 11+ | `.dmg` (Apple Silicon / Intel) | снимки, редактор |
| Linux | `.AppImage`, `.deb` | снимки, редактор |

Запись видео пока доступна только в Windows.

## Если система ругается

- **Windows:** «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** правый клик по приложению → «Открыть». Если пишет «повреждено»: `xattr -cr /Applications/Framivo.app`.
- **Linux:** сделай `.AppImage` исполняемым и запусти; для `.deb` — `sudo apt install ./файл.deb`.
